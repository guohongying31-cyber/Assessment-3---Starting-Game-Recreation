## 共同约束（PDF 第 1–4 页）

- [ ] 2D Sprite 项目，全部视觉素材和游戏脚本由学生本人创作。
- [ ] 素材与 Pac-Man 的黄色圆形及四色幽灵造型显著不同，也不临摹其他作品角色。
- [ ] 每个必需动画状态至少两张肉眼可分辨的帧；不能用静态图假装动画。
- [ ] 音频可以自制或来自有明确免费／免版税许可的来源；不能用原作变体。
- [ ] 不使用下载的游戏代码、资产商店素材或未获允许的附加插件。
- [ ] AI 提示及实际使用的输出已披露；不整段照搬 AI 生成代码。
- [ ] 不使用 Rigidbody 物理驱动运动、CharacterController 等；如后期只用于检测，
  Rigidbody2D 必须始终为 Kinematic。
- [ ] 不使用 Animated Tile 扩展。动画强化收集物手动放置。
- [ ] 逐档完成；前一档缺漏会使后一档无法获得评分。

Assessment 4 才要求主菜单、重制关卡、创新关卡三个场景及完整玩法。
Assessment 3 不要求键盘输入、吃点碰撞、墙壁碰撞或敌人移动。

## 35%：音频（PDF 第 8 页）

下列 **11 类音频** 全部导入 `Assets/Audio Clips`，名称可对应其用途。

- [ ] Intro：关卡开场音乐。
- [ ] StartScene：未来菜单场景音乐（A3 仍须准备该片段）。
- [ ] Ghost Normal：异兽正常状态循环音乐。
- [ ] Ghost Scared：异兽畏惧状态音乐。
- [ ] Ghost Dead：至少一只异兽处于死亡状态时的音乐。
- [ ] Move：修仙者移动但不收集灵气的音效。
- [ ] Pellet：收集灵气音效。
- [ ] Eat Ghost：封印异兽音效。
- [ ] Cherry：收集朱果音效。
- [ ] Wall：碰壁音效。
- [ ] Death：修仙者死亡／元神消散音效。
- [ ] 场景包含 AudioSource；按 Play 后先播 Intro，在片段结束或 3 秒
  到达时（较早者）切换到 Ghost Normal 并循环。
- [ ] 逐条检查可播放、无意外静音／截断、音量合适、许可与实际来源可追溯。

## 50%：Sprite（PDF 第 9、11–12 页）

- [ ] PacStudent：左右上下四套独立行走帧，不只是旋转同一套图；另有死亡帧。
- [ ] 四只异兽各有左右上下正常状态帧。
- [ ] 异兽左右上下畏惧状态帧、恢复状态帧和死亡状态帧。
- [ ] 普通灵气、破厄丹、朱果、生命图标。
- [ ] 外角、外墙、内角、内墙、T 连接、异兽出口封印六种墙体 Sprite。
- [ ] 关卡按 1–8 号八类布局素材组织，不为每种旋转角额外导出贴图。
  0 号选择不放 Sprite；Power Pellet 必须同时满足至少两帧的动画要求。
- [ ] 所有视觉素材导入 Unity，并在场景中能找到展示实例。
- [ ] 尺寸、PPU、Pivot 一致；角色不会超出一格通道。

## 65%：Animator（PDF 第 10 页）

- [ ] PacStudent 一个 Animator Controller，含四个 Walking 方向状态及 Dead。
- [ ] Power Pellet 有独立 Animator Controller。
- [ ] 异兽控制器以 `GhostAnimator_` 开头；每只具有四方向 Walking、
  四方向 Scared、Recovering、Dead，共 10 个状态。
- [ ] 可用一个控制器加三个 Override Controller，或四个独立控制器。
- [ ] Play 中可逐一看到修仙者与每只异兽的所有必需状态，强化收集物持续闪动。
- [ ] 循环动画展示至少 3 个循环且至少 2 秒（取较长者）；
  非循环动画至少完整播一遍。按该时长设置 Exit Time。
- [ ] 后续运动实例依照运动方向即时切换；展示实例的自动轮播不能抢占其方向。

## 75%：手动关卡（PDF 第 11–12 页）

- [ ] 数值区恰好取原 CSV 前 15 行 × 14 列；后半字符表和图例不得当作地图。
- [ ] 左上象限与 PDF 数组及示意图对应，各墙体正确旋转衔接。
- [ ] 左右镜像，再上下镜像；不重复底行。默认完整地图为 29 行 × 28 列。
- [ ] 中线只有一行，左右出口通道宽一格、通道出口无 pellet。
- [ ] 手动关卡真实保存在场景里，按 Play **之前**就在 Scene View 可见。
- [ ] Play 时相机完整显示四象限。按 Stop 后手动关卡仍然存在。
- [ ] 不能直接照搬原版完整 Level 01；按本题指定象限的镜像布局制作。
- [ ] 破厄丹动画对象手动摆放；普通墙体用旋转／镜像复用基础素材。

## 85%：移动（PDF 第 13 页）

- [ ] 使用课程要求的程序化 tween，运动独立于帧率。
- [ ] 绕左上角第一块内墙顺时针循环。以左上角为数组原点，路径为
  `(row 1,col 1) → (1,6) → (5,6) → (5,1) → (1,1)`。
- [ ] 每段速度相等且线性，不因水平／垂直距离不同而改变速度。
- [ ] 拐角立即转向并立即换成对应动画，播放不吃灵气时的移动音效。
- [ ] 在不同帧率下验证整圈时间、方向、轨迹和声效。
- [ ] 不使用 `Rigidbody.velocity`、`Vector3.MoveTowards()` 等代替 tween。

## 100%：LevelGenerator（PDF 第 14–15 页）

- [ ] 学生编写 `LevelGenerator.cs`，包含可由教师替换的 `int[,] levelMap`。
- [ ] `Start()` 只在运行时移除原手动 Level01，然后生成新的关卡。
- [ ] 从数组尺寸和邻居关系决定位置、旋转及镜像；不硬编码本题坐标表。
- [ ] 横向、纵向及双向镜像均正确；纵向不重复底行。
- [ ] 理解镜像与旋转不同，非对称墙体不能只旋转 180 度来替代反射。
- [ ] 相机适配任意合法地图大小及画面比例。
- [ ] 使用实例化或 Tilemap 放置，但连接规则必须由本人代码计算，不用 Rule Tiles。
- [ ] 测试更宽、更高、小地图、四种角向、T 连接、出口和镜像接缝。
- [ ] 默认地图生成结果与手动关卡相符，Stop 后手动关卡完整恢复。
- [ ] 换图后 PacStudent 仍保留原手动关卡位置的巡回路线（本题不要求自适应路线）。
